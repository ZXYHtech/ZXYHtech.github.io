This is a mobile-oriented adaptation of the upstream browser fishing game.
Retained open-source gameplay ideas/code structure: bait selection, simulated time and fish activity windows, cast/wait/bite flow, tap-to-reel challenge, catch history and localStorage persistence.

Adaptations for the ZXYHtech fishing web app:
- removed decorative external avatar/cloud image dependencies;
- simplified the page for small touch screens;
- shortened wait times for a compact embedded minigame;
- added bilingual labels;
- added `window.__IKUTAN_FISH_READY__` for automated host/runtime testing.

The upstream MIT license is preserved in `LICENSE`.
