🎣 MonadFish 游戏说明

V11 把操作说明统一放到这里，不再额外增加“操作”按钮。主界面保留原来的“游戏说明”，需要时从那里进入即可。

1. 一次完整钓鱼怎么操作

第 1 步点“抛竿”
第 2 步等鱼靠近鱼饵
第 3 步出现“提竿”马上点
第 4 步反方向控竿
第 5 步等待鱼上岸
  1. 抛竿：点击主按钮“抛竿”。
  2. 等待：不用连续点击，等鱼咬钩。
  3. 提竿：按钮变成“提竿”后立刻点一次。
  4. 遛鱼：鱼向左冲时向右倾手机或向右滑；鱼向右冲时反过来。
  5. 结束：鱼获会进入“背包”，可以查看或出售。

2. 📱 遛鱼与人物动作

  • 咬钩后，自研少年角色会从等待姿态切换为起身、拉竿、后仰发力和庆祝姿态。
  • 鱼往哪边冲，就往反方向控竿。支持手机左右倾斜；没有传感器时也可以左右滑动。
  • 搏鱼时画面会显示实时方向提示，不再另放一个“操作”按钮。
  • 当前版本的左右控竿主要用于人物动作、方向反馈与张力演出；真正的提竿判定仍由“提竿”时机决定，避免隐藏规则影响成功率。

3. 主界面中文对应

  • 抛竿原 CAST LINE
  • 提竿原 HOOK IT
  • 加速原 BOOST
  • 背包原 Inventory
  • 出行原 Travel
  • 钓鱼 / 任务 / 商店 / 烧烤 / 魔方 / 排行底部导航已统一中文化。

4. 鱼群显示

  • V11 关闭了额外叠加的低清大鱼群，优先恢复原游戏高分辨率鱼图。
  • 水下过大的鱼会自动缩小，主“抛竿 / 提竿”按钮保持在更高层级，避免被鱼挡住。
  • 鱼种与经济规则不因这次视觉修复而改变。

5. 常用功能

  • 钓鱼核心钓鱼流程。
  • 任务完成目标并领取奖励。
  • 商店补充鱼饵、升级鱼竿。
  • 烧烤把鱼获制作成料理。
  • 魔方抽取金币或鱼饵。
  • 排行查看成长与积分。
  • 背包查看、出售鱼获。
  • 出行进入地图与其他区域。
